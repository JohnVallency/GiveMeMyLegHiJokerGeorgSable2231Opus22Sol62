# Нарды • Клуб

Игровой клуб на Flutter с короткими нардами, «Шахматами 2» и рисовалкой. Нарды поддерживают игру с ботом, игру вдвоём на одном устройстве и сетевые комнаты.

[Открыть веб-версию](https://45.151.31.20:8443/) · [Скачать APK](dist/Nardy-Club.apk) · [Скачать серверную сборку](dist/Club-Server.tar.gz)

Для совместной игры каждому игроку нужен свой аккаунт. Один игрок создаёт комнату в шахматах или нардах и передаёт код второму.

## Экраны и управление

Главное меню → Играть → выберите соперника и ставку. Правила доступны из меню.

Портретное положение: компактная доска по центру, карточки игроков сверху и снизу. Альбомное: большой игровой стол, игроки слева и управление справа. Положение меняется автоматически при повороте без сброса текущей партии.

Светлые идут от 24 к 1, тёмные — от 1 к 24. Нажмите шашку, затем пункт с зелёной меткой. Для ввода с бара выберите шашку в центре доски; для снятия — шашку в доме и «Снять». Подсказка показывает рекомендуемый ход. Кости нарисованы с точками, объёмными гранями и анимацией броска. Шашки плавно перемещаются с подъёмом и тенью; взятая шашка уходит на бар, снятая — за край доски. Возможные ходы обозначаются полупрозрачными шашками в конечной позиции на пункте, включая верх занятой стопки. Ввод блокируется до завершения движения. Смена хода в режиме с другом происходит автоматически.

## Очки

Стартовый банк — по 1000 очков. Ставки: 25, 50, 100, 250. При начале партии ставка вычитается у светлых и, в режиме с другом, у тёмных. Победитель получает двойную ставку, то есть чистый выигрыш равен ставке. В игре с ботом вторую ставку предоставляет игра.

Выход, сдача или закрытие незавершённой партии считаются поражением светлых. При следующем запуске незавершённая партия рассчитывается один раз; в режиме с другом банк партии получает игрок тёмными. При нехватке очков нужно уменьшить ставку.

Очки условные: без платежей, покупок, вывода и реальных призов. Банк, исходное количество и статистика сохраняются локально: localStorage в браузере, файл в каталоге приложения на Android или в APPDATA/NardyClub на Windows. Очистка данных браузера или приложения удаляет банк. Сама партия после закрытия не восстанавливается.

## Запуск и сборка

```powershell
flutter pub get
flutter run -d chrome
flutter build web --no-web-resources-cdn
```

Веб-сборка: `build/web`. Раздайте её HTTP-сервером, например `python -m http.server 4185 --directory build/web`, затем откройте http://127.0.0.1:4185.

Android: `flutter run -d <идентификатор устройства>` или `flutter build apk --release`.
Windows: `flutter run -d windows` (нужны инструменты Visual Studio для C++).

```powershell
flutter analyze --no-pub
flutter test --no-pub
```

Если анализатор Windows падает на кириллическом пути с FormatException, откройте проект через junction с латинским именем: для этой копии создан `C:\dev\nardy_club`.

## Движок

`lib/engine.dart` перебирает допустимые последовательности с максимальным использованием костей. Новичок выбирает случайную последовательность; Тактик оценивает прогресс, закрытые пункты и взятия; Стратег учитывает угрозы одиночным шашкам. Это эвристический бот, без турнирной оценки силы.

Реализованы начальный бросок и переброс при равенстве, дубли, блокировка пунктов, взятие, приоритет бара, максимальное использование костей, старшая кость, дом, снятие и победа.

Тесты проверяют движок, полную партию ботов, смену хода в трёх размерах экрана, расчёт локальных ставок, рисовалку и форму входа. Снимки расположений создаются в `previews` при тестировании.

## Готовый APK

`dist/Nardy-Club.apk`: универсальный APK для Android 7.0+ (ARM32, ARM64 и x86_64), с пользовательской иконкой, фоном и изменённой формой пунктов. Подпись APK проверена apksigner. Это release-сборка для прямой установки с текущим отладочным сертификатом проекта; для публикации в магазине нужен отдельный постоянный release-ключ.

Сборка на этой машине выполнена из физической копии `C:\dev\nardy_apk_build`, поскольку Android Gradle Plugin отклоняет исходный путь с кириллицей. Для Java установлен параметр только в процессе сборки: `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\dev\tmp`. Изображения хранятся в `assets`.

## Общий аккаунт и комнаты

Веб-версия и API работают с одного адреса. Войдите или зарегистрируйтесь из главного меню. Общий баланс хранится в SQLite и загружается на другом устройстве после входа. В рисовалке завершённый штамп приносит одну монету при активном соединении и входе в аккаунт. Свободные штрихи и ластик не начисляют монеты. Локальные ставки в нардах используют отдельные очки, а кнопка их пополнения убрана.

В нардах и шахматах один игрок создаёт комнату, второй вводит код под своим аккаунтом. Сервер проверяет ход и очередность. Сетевые комнаты сохраняются. При повторном входе в комнату используется тот же код. Новые аккаунты и комнаты не импортируют данные старого сайта шахмат.

## Сервер

Из корня проекта после сборки Flutter запустите `node server/club.mjs`. Нужен Node.js 24. По умолчанию сервер слушает `127.0.0.1:4185`, выдаёт `build/web` и хранит данные в `server/data/club.sqlite`. Параметры `PORT`, `CLUB_BIND`, `CLUB_WEB` и `CLUB_DB` позволяют изменить эти пути. На публичном HTTPS задайте `CLUB_SECURE_COOKIE=1` и направьте обратный прокси на внутренний порт Node.

Для Android укажите публичный HTTPS-адрес при сборке: `flutter build apk --release --dart-define=CLUB_SERVER=https://<адрес>`. Веб-сборка использует тот же адрес, с которого загружена страница.
